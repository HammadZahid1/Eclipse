# ECLIPSE

> Explore the universe. Understand the motion.

ECLIPSE is a self-contained, browser-based interactive space simulation laboratory. It lets you explore a simulated solar system, manipulate a black-hole-inspired visualization, generate procedural galaxies, and experiment with a simplified orbital mechanics playground.

Everything runs locally in the browser. There is no backend, database, external API, API key, or third-party simulation service.

> **Note:** ECLIPSE uses simplified, visually driven models. It is an exploratory tool, not a scientifically exact representation of the universe.

## Status

Project bootstrap in progress. Full feature documentation will be added as the simulation modules are implemented.

## Quick start

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Typecheck and create a production build |
| `npm run preview` | Preview the production build locally |
| `npm run typecheck` | Run TypeScript checks |
| `npm run lint` | Run ESLint |
| `npm run test` | Run simulation logic unit tests |
| `npm run check` | Run all checks and a production build |

## Technology

React, TypeScript, Vite, Tailwind CSS, Three.js, React Three Fiber, Drei, Zustand, Framer Motion, Lucide React, and Vitest.
